It is designed to help students and security professionals learn vulnerability assessment, exploitation techniques, and defensive security concepts in a safe and controlled environment.

Setup

Usage

1. Start the virtual machine. 2. Use authorized security tools such as Nmap, Metasploit Framework, or Nessus to discover and analyze vulnerabilities in the controlled lab environment.
